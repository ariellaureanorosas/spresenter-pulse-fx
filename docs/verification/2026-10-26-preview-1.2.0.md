# Prévia sem iframe — 1.2.0

**Plugin:** 1.2.0
**SDK:** 0.5.0
**App:** Spresenter 0.3.50 (referência)
**Ambiente:** Windows, Node 24.19.0 / npm 11.17.0

## Motivo

O palco da prévia aparecia branco e não reagia ao clique. O componente usava um
`<iframe srcDoc sandbox="">` para renderizar o efeito.

O host embute a UI do plugin em um iframe de **origem opaca**
(`sandbox="allow-scripts"`, encontrado em `app.asar`), então o palco era um
iframe sandbox aninhado dentro de outro. Nessa combinação o documento não pintou
de forma confiável: sobrava a superfície branca, e o flash branco padrão
(`#ffffff`, alvo `full`) ficava invisível sobre ela.

Não havia violação de CSP nem erro do painel nos logs do app
(`%APPDATA%\spresenter\logs`).
