# Dica duplicada no palco — 1.2.1

**Plugin:** 1.2.1
**SDK:** 0.5.0
**App:** Spresenter 0.3.50 (referência)
**Ambiente:** Windows, Node 24.19.0 / npm 11.17.0

## Motivo

Ao passar o mouse sobre o palco, aparecia uma pílula "Repetir" no canto
inferior direito. Ela duplicava o botão **Repetir** do rodapé do cartão, que já
é a referência visual para repetir a animação.

## O que mudou

| Item | Antes | Depois |
|---|---|---|
| Dica sobre o palco | pílula "Repetir" no hover/foco | removida |
| Clique no palco | reinicia a animação | igual |
| Botão **Repetir** do rodapé | reinicia | igual |
| Teclado | foco no palco + Enter | igual, com anel de foco |
| Nome acessível do palco | "Repetir a prévia" | igual |

O botão que cobre o palco continua existindo (`aria-label` e `title`
mantidos), apenas sem conteúdo visual.
