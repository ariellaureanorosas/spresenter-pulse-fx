## Decisões registradas

### Distribuição

O repositório é **privado** (decisão do mantenedor). Consequências:

- A instalação por ZIP depende de acesso ao repositório e à página de releases
  para colaboradores autenticados.
- Badges que dependem de API pública (shields.io para release) não são
  confiáveis e devem ser removidos.
- O README não deve prometer download público.

### Compatibilidade mínima

`minAppVersion` foi alterado de `0.3.0` para **`0.3.50`**, com evidência:

1. O app instalado nesta máquina é **0.3.50** (`Spresenter.exe` → FileVersion).
2. Os templates oficiais embutidos no app usam `minAppVersion` igual à versão do
   app e `sdk` igual à versão do SDK (`__APP_VERSION__` / `__SDK_VERSION__`).
3. Outro plugin do mesmo autor, instalado e funcional, declara
   `"minAppVersion": "0.3.50"` e `"sdk": "0.5.0"` — exatamente a combinação
   usada aqui.
4. A versão anterior do Pulse FX declarava `minAppVersion: 0.3.0` com
   `sdk: 0.4.0`; não há evidência de que o SDK 0.5.0 funcione em 0.3.0.

O `sdk` permanece **0.5.0**.
