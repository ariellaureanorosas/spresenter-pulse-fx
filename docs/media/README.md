# Mídia do README

Os arquivos desta pasta são usados no `README.md`. Como o plugin é visual, a
mídia é parte da documentação.

## Especificação

| Arquivo | Formato | Tamanho | Conteúdo |
|---|---|---|---|
| `panel.png` | PNG | 1440×900 | Painel completo com um efeito em execução |
| `hit.gif` | GIF | ≤ 5 MB, 3–5 s | Disparo de Hit em tela cheia |
| `strobe.gif` | GIF | ≤ 5 MB, 3–5 s | Strobe com a trava ligada |
| `pulse.gif` | GIF | ≤ 5 MB, 3–5 s | Pulse em vinheta |
| `targets.png` | PNG | 1280×720 | Tela cheia, vinheta e moldura lado a lado |

## Regras

- Use uma saída real do Spresenter, não a prévia do painel, nos GIFs.
- Não inclua letras de músicas, nomes de pessoas ou conteúdo de terceiros.
- Prefira 30 fps e paleta reduzida para manter o arquivo pequeno.
- Nomeie em minúsculas, sem espaços.
- Ao trocar uma mídia, atualize a data em `docs/verification/` se a mudança for
  visual.

Enquanto os arquivos não existirem, o README não deve referenciá-los.
